# Contributing

1. Fork the repository and create a branch.
2. `pip install -e '.[dev]'` and run `pytest`.
3. Open a pull request that describes the change. Add tests for new behavior.

Never commit API keys, vault keys or other secrets. Report security issues privately to info@infinitumcorporation.ai (see SECURITY.md).
